# Visual Views Directory Index (`docs/views/`)

> **Status:** Active  
> **Purpose:** Thư mục lưu trữ các bản hiển thị trực quan (Standalone HTML Artifacts: Architecture Dashboards, Interactive Diagrams, Canvas Prototypes) được tạo **theo yêu cầu riêng của người dùng** (On-demand generation).

---

## 1. Nguyên tắc Quản lý
- Các tài liệu cốt lõi trong `docs/business/`, `docs/architecture/`, `docs/implementation/` **chỉ sử dụng Pure Markdown và Mermaid**.
- Khi người dùng yêu cầu xuất file HTML tương tác hoặc bản đồ kiến trúc trực quan, các file HTML tự đóng gói (self-contained) sẽ được lưu tại đây.
- Các tài liệu Markdown có thể dẫn link trực tiếp tới các file HTML tại thư mục này.

## 2. Danh mục Views hiện có
*(Chưa có view HTML nào được tạo. Sẽ được sinh tự động khi người dùng yêu cầu trực quan hóa qua các skill chuyên biệt như `diagram-design` hoặc `html-diagram`.)*
