# ADR-001: Chuyển đổi Backend sang Python (FastAPI) & Tách biệt Deterministic Data

> **Status:** Accepted  
> **Date:** 2026-10-12  
> **Deciders:** Technical Lead, Antigravity Agent  

---

## 1. Context & Problem Statement
Dự án gốc được viết bằng Go. Tuy nhiên, người học mong muốn xây dựng lại bằng hệ sinh thái Python để thuận tiện cho việc học tập, nghiên cứu và tích hợp các công cụ AI hiện đại (FastAPI, Pydantic, NumPy, Pydantic AI). Cần đảm bảo hệ thống duy trì được tính nhẹ nhàng, kiểm soát 100% dòng dữ liệu và không phụ thuộc vào các framework AI cồng kềnh.

## 2. Decision
1. **Lựa chọn Python 3.11+ và FastAPI** làm web framework chính, quản lý gói thông qua `uv` và virtual environment `.venv`.
2. **Triết lý No-Framework**: Tự viết ReAct loop (tối đa 6 turns), thuật toán Okapi BM25 và tính toán Cosine Similarity trên SQLite. Sau đó, xây dựng module Pydantic AI song song để đối chiếu benchmark.
3. **Tách biệt Deterministic Data**: Toàn bộ tính toán tài chính (CLV, AOV, số lần giao trễ) do code thuần Python thực hiện, LLM không được làm toán.
4. **Grounding Guard**: Toàn bộ ID thực thể do LLM sinh ra phải được kiểm tra chéo với DB thật trước khi xuất ra giao diện.

## 3. Consequences
- **Tích cực:** Code dễ hiểu, dễ debug, kiểm soát được token và chi phí, tận dụng được tính năng type safety mạnh mẽ của Pydantic v2.
- **Tiêu cực / Rủi ro:** Cần tự bảo trì thuật toán BM25 và ReAct loop thay vì dùng thư viện có sẵn; cần tối ưu hóa xử lý chuỗi tiếng Việt.
