# API Specification — Release 1: Copilot Support

> **Status:** Draft  
> **Release:** Release 1  
> **Base URL:** `/api/v1`  

---

## 1. Endpoints

### 1.1. Single-Call Assist
- **URL:** `POST /api/v1/assist`
- **Request Body:**
  ```json
  {
    "customer_id": "cust_001",
    "recent_messages": [
      { "sender": "customer", "text": "Shop ơi, máy xay sinh tố cối bị nứt rồi..." }
    ]
  }
  ```
- **Response (200 OK):**
  ```json
  {
    "customer_profile": { "name": "Nguyễn Văn A", "tier": "Silver", "clv": 2520000, "delay_rate": 0.67 },
    "analysis": "Lỗi kép: giao trễ 4 ngày và cối thủy tinh nứt.",
    "suggestions": [
      { "tone": "Empathetic", "content": "Dạ shop thật sự xin lỗi anh..." },
      { "tone": "Concise", "content": "Dạ shop xin lỗi vì đơn #10032..." },
      { "tone": "Formal", "content": "Dạ Nhà Gọn thành thật xin lỗi anh..." }
    ]
  }
  ```

### 1.2. ReAct Agent Run (SSE Stream)
- **URL:** `POST /api/v1/agent/run`
- **Request Body:** Tương tự như `POST /api/v1/assist`
- **Response:** `text/event-stream` stream liên tục các event `turn_start`, `thought`, `tool_call`, `tool_result`, `suggestion`, `done`.
