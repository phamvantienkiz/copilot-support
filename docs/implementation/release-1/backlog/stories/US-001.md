## 1. User Story Statement

**As a** Developer phát triển backend Copilot,  
**I want to** nạp 4 file JSON dữ liệu mẫu của shop "Nhà Gọn" (`customers.json`, `orders.json`, `products.json`, `complaint-cases.json`) cùng `shop_benchmarks.json` và xây dựng engine BM25 tokenizer tiếng Việt không dấu,  
**So that** hệ thống có nền tảng dữ liệu thực tế chuẩn xác và công cụ tìm kiếm từ khóa độc lập, không phụ thuộc vào framework bên thứ ba cồng kềnh.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Nạp đầy đủ 4 file dữ liệu và bảng Benchmark shop]
- **Given** server khởi động trong môi trường virtualenv `.venv`,
- **When** module catalog và data loader đọc các tệp JSON trong thư mục dữ liệu,
- **Then** toàn bộ bản ghi của khách hàng `cus_003` (Nguyễn Văn A, 3 đơn hàng, voucher cũ `XINLOI30K`), sản phẩm `prd_001` (Máy xay Zenka B600) và ngưỡng benchmark shop (CLV median 3,93tr, Đúng hẹn 92%) được nạp vào bộ nhớ mà không có lỗi format,
- **And** log hệ thống ghi nhận số lượng bản ghi nạp thành công.

### AC2: [Validation & Search - Tìm kiếm từ khóa tiếng Việt không dấu]
- **Given** trong danh mục có sản phẩm "Máy xay sinh tố Zenka B600 cối thủy tinh" và đơn hàng `#10032`,
- **When** engine BM25 nhận chuỗi truy vấn không dấu `"may xay zenka"` hoặc `"don 10032"`,
- **Then** tokenizer chuẩn hóa chuỗi (bỏ dấu, chuyển chữ thường, loại bỏ stop words),
- **And** trả về kết quả sản phẩm `prd_001` hoặc đơn `#10032` với điểm xếp hạng BM25 chuẩn hóa cao nhất ($\text{Score} \ge 0.9$).

### AC3: [Edge Case - Loại bỏ Stop Words và Ký tự đặc biệt]
- **Given** câu truy vấn chứa nhiều từ nối rác hoặc ký tự đặc biệt: `"shop ơi cối xay và bị nứt nẻ thế nào vậy???"`,
- **When** tokenizer xử lý tách từ,
- **Then** các từ dừng (`"ơi"`, `"và"`, `"thế nào"`, `"vậy"`) và dấu câu được loại bỏ,
- **And** giữ lại các từ khóa trọng tâm: `["cối", "xay", "nứt", "nẻ"]`.

### AC4: [Negative Path - Thiếu file dữ liệu hoặc JSON malformed]
- **Given** một trong 4 tệp JSON bị thiếu hoặc có lỗi cú pháp JSON,
- **When** loader khởi tạo ứng dụng,
- **Then** hệ thống tung ngoại lệ rõ ràng (`DataInitializationError`),
- **And** chặn tiến trình khởi động kèm thông báo lỗi trỏ đúng tên file bị hỏng thay vì âm thầm bỏ qua.
