**Tầng tài liệu:** Implementation Layer  
**Release:** Release 1 (MVP)  
**Traceability:** Map to `NFR-04` trong [docs/implementation/release-1/srs.md](../../srs.md)  
**Priority:** P1 (Should)

## 1. User Story Statement

**As a** Developer hoặc Tester kiểm thử hệ thống,  
**I want to** ứng dụng có chế độ Replay Mode phát lại các bản ghi JSON mẫu của vòng lặp Agent và hội thoại chat đã được lưu trước trong thư mục `public/replay/` mà không cần gọi API DeepSeek thật,  
**So that** tôi có thể kiểm thử toàn diện giao diện, demo và debug luồng hiển thị mà không tốn chi phí token API và không phụ thuộc vào kết nối mạng bên ngoài.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Kích hoạt Replay Mode qua URL Query Param]
- **Given** người dùng mở ứng dụng với tham số `?replay=1&autoplay=1`,
- **When** trang web khởi chạy,
- **Then** hệ thống ngắt toàn bộ các cuộc gọi API mạng tới LLM,
- **And** tự động đọc dữ liệu bản ghi từ tệp `public/replay/blender-complaint.json`,
- **And** mô phỏng chính xác từng bước nhảy của Agent (Vòng 1 thought, gọi 4 tool, Vòng 2 soạn gợi ý) theo đúng độ trễ được giả lập.

### AC2: [Validation & UI Controls - Nút Điều khiển Replay (Pause / Step / Restart)]
- **Given** chế độ Replay Mode đang hoạt động,
- **When** người kiểm thử nhìn vào thanh công cụ điều khiển Replay,
- **Then** giao diện cung cấp các nút: Tạm dừng (Pause), Tiếp tục (Play), Nhảy bước kế tiếp (Step Forward) và Chạy lại từ đầu (Restart),
- **And** thanh tiến trình hiển thị rõ ràng vị trí bước đang phát lại (ví dụ: `Bước 3 / 6`).

### AC3: [Negative Path - Thiếu file replay hoặc cấu trúc replay lỗi]
- **Given** URL yêu cầu file replay không tồn tại (`?replay=invalid_case`),
- **When** engine nạp file,
- **Then** hệ thống hiển thị thông báo lỗi nhẹ nhàng: "Bản ghi Replay không tìm thấy",
- **And** tự động quay về chế độ Live Mode bình thường.
