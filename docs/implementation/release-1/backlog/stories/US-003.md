# User Story: US-003 - Single-Call Assist Service & Soạn 3 Mẫu Phản hồi theo Tone

**Tầng tài liệu:** Implementation Layer  
**Release:** Release 1 (MVP)  
**Traceability:** Map to `FR-06` trong [docs/implementation/release-1/prd.md](../../prd.md)  
**Priority:** P0 (Must)  
**Estimable Effort:** 5 Story Points

## 1. User Story Statement

**As a** Người trực CSKH (Support Operator),  
**I want to** hệ thống cung cấp chế độ hỗ trợ nhanh (Single-Call Assist) tự động gom ngữ cảnh và gọi LLM 1 lần để soạn sẵn 3 mẫu câu trả lời theo 3 tone khác nhau (Đồng cảm, Ngắn gọn, Trang trọng),  
**So that** tôi có ngay phương án phản hồi chuẩn chính sách chỉ trong 2-3 giây mà không cần chờ đợi vòng lặp agent phức tạp.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Soạn thảo đầy đủ 3 tone phản hồi chuẩn]
- **Given** người dùng kích hoạt chế độ Single-Call Assist với 3 tin nhắn gần nhất của khách `cus_003`,
- **When** service gom ngữ cảnh từ BM25 và gửi prompt JSON mode tới DeepSeek LLM,
- **Then** LLM trả về đúng 3 mẫu gợi ý:
  - **Empathetic (Đồng cảm):** Nhận lỗi của shop, dặn không dùng cối nứt, hỗ trợ đổi mới hỏa tốc 2 chiều tận nơi, tặng voucher 100.000đ.
  - **Concise (Ngắn gọn):** Nêu rõ mã đơn `#10032`, xác nhận đổi mới trong 7 ngày, voucher 100k, tùy chọn hoàn tiền 24h.
  - **Formal (Trang trọng):** Văn phong doanh nghiệp chuẩn thương hiệu Nhà Gọn.
- **And** tổng thời gian phản hồi của Single-call assist $\le$ 3.0 giây.

### AC2: [Validation & Auto-Repair - Sửa lỗi cú pháp JSON]
- **Given** LLM trả về chuỗi JSON bị thiếu dấu đóng ngoặc hoặc sai định dạng schema,
- **When** JSON validator của hệ thống phát hiện lỗi parse,
- **Then** hệ thống tự động kích hoạt cơ chế Auto-Repair: gửi lại đoạn JSON lỗi kèm thông báo yêu cầu LLM sửa đúng cấu trúc (tối đa 1 lần retry),
- **And** nếu lượt retry thành công, trả về kết quả bình thường cho người trực mà không làm gián đoạn phiên làm việc.

### AC3: [Negative Path - Lỗi kết nối LLM API hoặc Quá lượt retry]
- **Given** cổng API DeepSeek bị mất kết nối hoặc lượt Auto-Repair thứ hai vẫn lỗi cú pháp,
- **When** service xử lý ngoại lệ,
- **Then** hệ thống ghi log cảnh báo chi tiết,
- **And** trả về phản hồi fallback thân thiện: hiển thị thông báo "Không thể khởi tạo gợi ý tự động lúc này" kèm nút bấm "Thử lại".

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC TUÂN THỦ)

> ⛔ **Cảnh báo cho AI Coding Agent:** Đọc và tuân thủ các quy tắc sau trước khi sinh code:

1. **AI & Prompt Invariants** ([06-ai-architecture.md](../../../architecture/06-ai-architecture.md)):
   - Bắt buộc áp dụng JSON Mode với Pydantic Schema `SuggestionResponse`.
   - Giới hạn retry auto-repair tối đa đúng 1 lần (`max_repair_attempts = 1`) để tránh lãng phí chi phí gọi API.
2. **Security & Human-in-the-Loop** ([07-security-architecture.md](../../../architecture/07-security-architecture.md)):
   - Single-call assist chỉ tạo văn bản gợi ý cho Operator duyệt; **tuyệt đối không dispatch tin nhắn ra cổng chat của khách hàng.**
3. **Integration Standards** ([08-integration-architecture.md](../../../architecture/08-integration-architecture.md)):
   - Kết nối với client DeepSeek v4.1 Flash thông qua module `backend/app/services/llm/client.py`.
