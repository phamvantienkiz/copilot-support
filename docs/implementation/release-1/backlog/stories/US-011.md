# User Story: US-011 - Top Banner Giám sát Hiệu năng, Độ trễ & Chi phí Vận hành DeepSeek Flash

**Tầng tài liệu:** Implementation Layer  
**Release:** Release 1 (MVP)  
**Traceability:** Map to `FR-09` trong [docs/implementation/release-1/prd.md](../../prd.md)  
**Priority:** P1 (Should)  
**Estimable Effort:** 3 Story Points  

---

## 1. User Story Statement

**As a** Quản lý Shop / Business Owner,  
**I want to** màn hình hiển thị thanh trạng thái trên cùng (Top Banner) ghi nhận chi tiết mô hình AI đang chạy (`DeepSeek v4.1 Flash`), tổng thời gian xử lý, số lần gọi model, số lượt tra cứu và ước tính chi phí API thực tế ($0,0016 / lượt chat, $1,6 / 1.000 lượt),  
**So that** tôi theo dõi sát sao hiệu năng kỹ thuật, kiểm soát 100% ngân sách vận hành AI và chứng minh được hiệu quả kinh tế vượt trội của giải pháp Copilot.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Hiển thị đầy đủ thông số hiệu năng sau phiên chạy]
- **Given** Agent hoàn tất quá trình suy luận và phản hồi cho tin nhắn của khách `cus_003`,
- **When** thanh trạng thái Top Banner cập nhật dữ liệu từ event `copilot_payload`,
- **Then** banner hiển thị đúng 2 dòng thông số chuẩn:
  - Dòng 1: `Lần chạy này: DeepSeek v4.1 Flash · 21,0 giây · 3 lần gọi model · 4 lần tra cứu.`
  - Dòng 2: `Chi phí khi gọi thẳng API DeepSeek: từ $0,0016 một lượt, 1.000 lượt chat từ $1,6.`
- **And** các con số phản ánh đúng giá trị thời gian và lượt gọi thực tế của phiên.

### AC2: [Validation & Cost Meter Calculation - Tính toán chi phí dựa trên Token thực]
- **Given** module `Meter` ghi nhận phiên làm việc tiêu tốn: 1.820 prompt tokens (Turn 1) + 7.040 tokens (Turn 2),
- **When** hệ thống tính toán chi phí theo bảng giá DeepSeek API ($0.14 / 1M prompt tokens, $0.28 / 1M completion tokens),
- **Then** chi phí tính toán xấp xỉ $0.0016 USD,
- **And** hệ thống định dạng số tiền hiển thị theo chuẩn tiếng Việt (`$0,0016 một lượt`).

### AC3: [Edge Case - Trong lúc Agent đang chạy (Trạng thái Active / In-progress)]
- **Given** Agent mới bắt đầu chạy và đang ở Vòng 1/6,
- **When** người dùng quan sát thanh Top Banner,
- **Then** đồng hồ đo thời gian hiển thị đếm giây tăng dần theo thời gian thực (ví dụ: `Đang chạy: DeepSeek Flash · 3,5 giây...`),
- **And** chuyển sang hiển thị tổng kết chi phí ngay khi phiên kết thúc.

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC TUÂN THỦ)

> ⛔ **Cảnh báo cho AI Coding Agent:** Đọc và tuân thủ các quy tắc sau trước khi sinh code:

1. **Meter Module Invariant** ([06-ai-architecture.md](../../../architecture/06-ai-architecture.md)):
   - Module `backend/app/services/llm/meter.py` chịu trách nhiệm đếm tokens, số lần gọi model và số lượt tool calls.
   - Tuyệt đối không hardcode tĩnh chuỗi số liệu chi phí; phải tính toán từ `usage` thực tế của response LLM.
2. **Design Tokens & Placement** ([11-frontend-system-design.md](../../../architecture/11-frontend-system-design.md) & [12-design-system.md](../../../architecture/12-design-system.md)):
   - Banner đặt cố định ở mép trên cùng của Workspace (`Top Metric Bar`), viền mờ `1px solid var(--color-border-muted)`.
   - Màu chữ tiêu đề: xanh lá cây dịu hoặc trắng ngà (`var(--color-text-primary)`), chữ phụ dùng `var(--color-text-secondary)`.
