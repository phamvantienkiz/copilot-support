# User Story: US-005 - ReAct Agent Loop với Parallel Tool Calling (4 Tools Đồng thời)

**Tầng tài liệu:** Implementation Layer  
**Release:** Release 1 (MVP)  
**Traceability:** Map to `FR-07` trong [docs/implementation/release-1/prd.md](../../prd.md)  
**Priority:** P0 (Must)

---

## 1. User Story Statement

**As a** Người trực CSKH (Support Operator),  
**I want to** Agent vận hành vòng lặp ReAct tự chủ (ReAct Agent Loop) có khả năng kích hoạt đồng thời nhiều công cụ tra cứu (Parallel Tool Calling) trong Vòng 1 và tự nhận diện dừng lại ở Vòng 2 khi đã đủ dữ liệu,  
**So that** hệ thống tự động thu thập toàn diện thông tin đơn hàng, sản phẩm và tiền lệ xử lý sự cố trong thời gian tối ưu (~20 giây) mà không bị kẹt trong vòng lặp vô tận.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Vòng 1: Kích hoạt đồng thời 4 Tools tra cứu]
- **Given** khách hàng `cus_003` gửi tin nhắn khiếu nại "máy xay bể cối + giao trễ",
- **When** ReAct Agent bắt đầu Vòng 1/6 (Turn 1),
- **Then** Agent sinh Thought: *"Tôi sẽ tra đơn máy xay của khách, sản phẩm liên quan, và các case đã xử lý cho cả vấn đề giao trễ lẫn hàng nứt."*,
- **And** hệ thống kích hoạt chạy đồng thời (par) đúng 4 Read-only Tools:
  1. `search_orders("máy xay sinh tố giao...")`
  2. `search_products("máy xay Zenk...")`
  3. `search_cases("giao trễ nhiều lần")`
  4. `search_cases("cối thủy tinh nứt khi...")`,
- **And** thu thập đủ 16 bản ghi kết quả trong thời gian $\le$ 2.5 giây.

### AC2: [Happy Path - Vòng 2: Nhận diện đủ dữ liệu và tổng hợp kết quả]
- **Given** 16 bản ghi kết quả từ Vòng 1 được nạp lại vào ngữ cảnh của Agent ở Vòng 2/6 (Turn 2),
- **When** Agent suy luận tiếp theo,
- **Then** Agent đưa ra Thought: *"Đủ dữ liệu, không gọi thêm tool."*,
- **And** chuyển thẳng sang Action: *"Soạn gợi ý từ 16 bản ghi"*, sinh ra cấu trúc JSON hoàn chỉnh gồm: `ai_assessment`, `context_warning` và 3 mẫu `suggestions`.

### AC3: [Validation & Safety - Giới hạn cứng 6 vòng lặp (Max Turns)]
- **Given** một tình huống khiếu nại quá mơ hồ khiến LLM liên tục gọi tool tra cứu,
- **When** số vòng lặp đạt ngưỡng `turn = 6`,
- **Then** vòng lặp ReAct bị cưỡng chế dừng lại ngay lập tức,
- **And** kích hoạt hàm tổng hợp khẩn cấp trên các dữ liệu đã thu thập được từ các vòng trước, ngăn ngừa vượt trần chi phí API và tràn bộ nhớ.

### AC4: [Negative Path - Tool tra cứu trả về kết quả rỗng]
- **Given** khách hàng nhắc đến một mã sản phẩm hoàn toàn không tồn tại trong kho (ví dụ: `"máy giặt sấy SolarX"`),
- **When** tool `search_products` thực thi,
- **Then** tool trả về kết quả `[]` (rỗng) mà không làm sập tiến trình,
- **And** Agent nhận diện được sản phẩm không tồn tại để phản hồi phù hợp trong Thought tiếp theo.

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC TUÂN THỦ)

> ⛔ **Cảnh báo cho AI Coding Agent:** Đọc và tuân thủ các quy tắc sau trước khi sinh code:

1. **ReAct Loop & Cost Control** ([06-ai-architecture.md](../../../architecture/06-ai-architecture.md)):
   - Khởi tạo ReAct loop thuần bằng Python (khoảng 80-120 dòng code), không dùng LangChain Agent Executor hay CrewAI.
   - Giới hạn cứng: `max_turns = 6`.
2. **Security & Read-Only Invariant** ([07-security-architecture.md](../../../architecture/07-security-architecture.md)):
   - Toàn bộ 6 Tools cấp cho Agent bắt buộc phải là **chỉ đọc (`read-only`)**. Tuyệt đối không cấp tool có quyền ghi/sửa dữ liệu hoặc tool tự gửi tin nhắn.
3. **Async / Parallel Execution** ([09-design-principles.md](../../../architecture/09-design-principles.md)):
   - Các lệnh gọi tool trong cùng 1 turn phải được thực thi bất đồng bộ bằng `asyncio.gather()` để tối ưu hóa thời gian chờ (latency).
