**Tầng tài liệu:** Implementation Layer  
**Release:** Release 1 (MVP)  
**Traceability:** Map to `FR-08` trong [docs/implementation/release-1/prd.md](../../prd.md)  
**Priority:** P0 (Must)

## 1. User Story Statement

**As a** Developer phát triển backend Copilot,  
**I want to** thiết lập cơ sở dữ liệu vector lưu trữ trực tiếp trong SQLite (`embeddings.sqlite`) và cài đặt công thức xếp hạng Hybrid Search ($0.3 \times \text{BM25} + 0.7 \times \text{Semantic Cosine}$),  
**So that** hệ thống tìm kiếm chính xác tuyệt đối các mã định danh/từ khóa đồng thời hiểu trọn vẹn từ lóng và ngôn ngữ tự nhiên của khách hàng mà không cần cài đặt các Vector Database ngoại lai phức tạp.

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy Path - Đồng bộ Vector Embeddings vào SQLite]
- **Given** danh mục sản phẩm và playbook các case khiếu nại của shop Nhà Gọn,
- **When** script `sync_embeddings` chạy khởi tạo lần đầu,
- **Then** toàn bộ văn bản mô tả được chuyển thành vector float32 thông qua DeepSeek Embedding API,
- **And** lưu trữ tuần tự vào bảng `embeddings` trong file SQLite cục bộ với các trường `id`, `doc_type`, `entity_code`, `content`, `vector`, `is_pinned`.

### AC2: [Happy Path - Tìm kiếm từ lóng bằng Semantic kết hợp BM25]
- **Given** khách hàng nhắn tin phàn nàn dùng từ lóng: `"đồ xay tới nơi bị bể tan tành"`,
- **When** module Hybrid Search tính toán độ tương đồng trên tập case khiếu nại,
- **Then** thành phần Semantic (Cosine Similarity) đạt điểm cao ($\ge 0.85$) nhờ nhận diện *"bể"* đồng nghĩa với *"nứt vỡ"*,
- **And** điểm tổng hợp $\text{FinalScore} = 0.3 \times \text{BM25} + 0.7 \times \text{Semantic}$ đưa case `case_shattered_glass_delivery` lên vị trí số 1.

### AC3: [Validation & Formula - Chuẩn hóa điểm số trong khoảng [0, 1]]
- **Given** điểm BM25 gốc có thể vượt quá 1.0 tùy thuộc vào độ dài tài liệu,
- **When** thuật toán Hybrid Search tính toán điểm xếp hạng cuối cùng,
- **Then** điểm BM25 bắt buộc được chuẩn hóa qua hàm Min-Max hoặc Sigmoid về khoảng $[0.0, 1.0]$,
- **And** điểm kết hợp cuối cùng đảm bảo luôn nằm trong đoạn $[0.0, 1.0]$.

### AC4: [Edge Case - Vector rỗng hoặc Query chỉ chứa ký tự đặc biệt]
- **Given** câu truy vấn của người dùng chỉ chứa dấu câu hoặc khoảng trắng (ví dụ: `"... ???"`),
- **When** engine tìm kiếm hybrid tiếp nhận câu truy vấn,
- **Then** hệ thống không tung ngoại lệ tính toán Cosine (`DivisionByZero`),
- **And** trả về danh sách rỗng an toàn kèm mã trạng thái thành công.

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC TUÂN THỦ)

> ⛔ **Cảnh báo cho AI Coding Agent:** Đọc và tuân thủ các quy tắc sau trước khi sinh code:

1. **Data Model Guardrails** ([05-data-architecture.md](../../../architecture/05-data-architecture.md)):
   - Bảng vector bắt buộc lưu trong SQLite file `backend/data/embeddings.sqlite`.
   - Cột `vector` phải lưu dưới dạng BLOB nhị phân (Float32 serialized).
2. **Formula Invariant** ([06-ai-architecture.md](../../../architecture/06-ai-architecture.md)):
   - Trọng số bắt buộc cố định: $\text{Weight}_{\text{BM25}} = 0.3$, $\text{Weight}_{\text{Semantic}} = 0.7$.
   - Tuyệt đối không thay đổi tỷ lệ trọng số nếu không có yêu cầu từ PO.
3. **No-Framework Invariant** ([09-design-principles.md](../../../architecture/09-design-principles.md)):
   - Tự viết hàm tính Cosine Similarity bằng NumPy hoặc math thuần; không cài đặt ChromaDB, Pinecone hay Faiss.
